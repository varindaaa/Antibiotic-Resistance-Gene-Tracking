🧬 Sequence-Based Antibiotic Resistance Gene Analysis
This project analyzes antibiotic resistance genes, specifically from the NDM (New Delhi metallo-beta-lactamase) family. We use tools like NCBI BLAST for sequence similarity, MEGA for phylogenetic analysis, Python for exploratory data analysis (EDA), and SQL for structured querying.

📝Project Overview
This project analyzes the **blaNDM gene** in *Klebsiella pneumoniae* to study antibiotic resistance patterns. By combining **sequence analysis**, **phylogenetics**, and **data exploration**, it uncovers evolutionary relationships and organism distribution.
